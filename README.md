# 1.44MB 공모전 — 병행 프로토타입

두 게임은 외부 엔진이나 런타임 없이 각각 독립된 Windows x64 GUI 실행 파일로 빌드된다.

| 게임 | 실행 파일 | 현재 크기 | 핵심 조작 |
|---|---|---:|---|
| 집게는 내가 잡는다 | `grill_game/tongs.exe` | 9,216바이트 | 좌클릭 드래그, 우클릭 뒤집기, `R` 재시작 |
| 아빠 온다 | `dad_game/dad_game.exe` | 9,216바이트 | `J` 게임, `K` 모니터, `Space` 침대, `F11` 전체화면 |

## 집게는 내가 잡는다

고기를 불판으로 옮기고 양면을 뒤집어 익힌 뒤 접시에 서빙하는 60초 점수 게임이다. 양쪽 익힘 막대가 초록색일 때 서빙하면 점수와 콤보를 얻는다.

```powershell
cd C:\Dev\1.44\grill_game
cmd /c build.bat
.\tongs.exe
```

## 아빠 온다

`J`를 누르는 동안 몰래 게임해 점수를 얻는다. 발소리가 들리면 `K`로 모니터를 끄고 `Space`로 침대에 누워야 한다. 둘 중 하나라도 빼먹으면 들킨다. `F11`로 같은 EXE에서 창 모드와 전체화면을 전환한다.

```powershell
cd C:\Dev\1.44\dad_game
cmd /c build.bat
.\dad_game.exe
```

## 검증

- 두 프로젝트 모두 `build.bat` 재빌드 성공
- 두 실행 파일 모두 `--self-test` 종료 코드 0
- PE32+ x64 / Windows GUI 확인
- 각각 1,474,560바이트 제한의 1% 미만

현재 단계는 재미를 비교하기 위한 최소 프로토타입이다. 다음 단계에서는 콘텐츠를 늘리기 전에 직접 플레이해 어느 조작이 더 즉각적으로 재미있는지 확인한다.
