# 아빠 온다! — 프로토타입

몰래 컴퓨터를 하다가 발소리가 들리면 모니터를 끄고 자는 척하는 60초 반응 게임입니다.

- `J` 누르고 있기: 컴퓨터 게임, 점수 상승. 꺼진 모니터도 자동으로 켜집니다.
- `K` 한 번: 모니터 끄기. 캐릭터는 아직 컴퓨터 앞에 있습니다.
- `Space` 한 번: 침대에 누워 계속 자는 척합니다.
- 안전 조건: 문이 열릴 때 `모니터 꺼짐 + 자는 척`을 모두 만족해야 합니다.
- `F11`: 창 모드/경계 없는 전체화면 전환
- `Enter`: 시작/재시작
- `Esc`: 종료

기본은 심사와 문제 해결이 쉬운 창 모드입니다. 전체화면도 같은 EXE에서 동작하므로 배포 파일이 늘어나지 않습니다.

`build.bat`을 실행하면 외부 라이브러리 없이 `dad_game.exe`를 만들고 내장 self-test를 수행합니다.
