# 아빠 온다! — 프로토타입

몰래 컴퓨터를 하다가 아빠가 들어오기 전에 모니터를 끄고 자는 척하는 60초 긴장 게임입니다.

- `J` 누르고 있기: 컴퓨터 게임, 점수 상승. 꺼진 모니터도 자동으로 켜집니다.
- `K` 한 번: 모니터 끄기. 캐릭터는 아직 컴퓨터 앞에 있습니다.
- `Space` 한 번: 침대에 누워 계속 자는 척합니다.
- 안전 조건: 문이 열릴 때 `모니터 꺼짐 + 자는 척`을 모두 만족해야 합니다.
- `F11`: 창 모드/경계 없는 전체화면 전환
- `Enter`: 시작/재시작
- `Esc`: 종료

그래픽은 밝은 방 기준판 하나에 플레이어, 밝게 보정한 도트 FPS 화면, 열린 문·아빠 레이어를 합성합니다. 아빠가 오기 직전에는 닫힌 나무문 위에 `쿵.. 쿵..` 자막을 보여 준 뒤 아빠가 바로 등장합니다. 첫 예고는 0.9초, 이후는 0.7초, 마지막 20초에는 0.6초로 짧아집니다. 문 비주얼은 여전히 `닫힌 문 → 열린 문 + 이미 들어온 아빠` 두 종뿐이며 반쯤 열린 중간 프레임은 없습니다.

J를 누르는 동안에만 큰 화면 흔들림, 커진 입력 픽셀·총구 화염, 모니터 주변에 동시에 쌓이는 여러 점수 팝업을 표시합니다. 들킨 순간에는 더 강한 흔들림·붉은 충격 테두리·`들켰다!`를 표시합니다. 기본 화면에는 클릭·입력·점수 효과를 표시하지 않습니다.

배경음악은 사용하지 않습니다. J 입력 중에는 `game.wav`를 반복하고, 아빠 등장 예고에는 증폭·저음 처리한 `stomp.wav`를 짧은 간격으로 두 번 재생합니다. 문이 실제로 열리는 순간에만 직접 녹음한 `door_open.wav`를 한 번 재생하며, 들킨 경우에는 0.35초 뒤 `founded.wav`를 재생합니다. 제출용 실행 파일에는 모노 8비트 WAV로 변환해 내장합니다.

자는 척하면 불을 끈 것처럼 방 전체가 어두워집니다. 모니터가 켜진 채로 자면 주변 방은 어두운 상태를 유지하고 FPS 화면만 밝게 남습니다. UI 문자는 `PF스타더스트 Regular` 90자(`.`·`쿵`·`몰` 포함)를 비트맵 아틀라스로 내장하고, 제목·경고·점수 팝업처럼 강조할 문자에는 어두운 외곽선 뱅크를 함께 사용합니다. 사용자 PC에 폰트를 설치할 필요가 없습니다.

기본은 심사와 문제 해결이 쉬운 창 모드입니다. 전체화면도 같은 EXE에서 동작하므로 배포 파일이 늘어나지 않습니다.

`build.bat`을 실행하면 외부 런타임 라이브러리 없이 `dad_game.exe`를 만들고 내장 self-test를 수행합니다. 그래픽 원본에서 BMP와 10개 상태 검증본을 다시 만들 때는 `tools/build_final_assets.py`를 사용합니다.

폰트 아틀라스를 다시 만들 때만 합법적으로 보유한 PF Stardust 파일을 빌드 입력으로 지정합니다. 원본 폰트 파일은 프로젝트에 포함하지 않습니다.

```powershell
python tools/build_font_atlas.py --font C:\path\to\PFStardust.woff
python tools/build_final_assets.py
```
