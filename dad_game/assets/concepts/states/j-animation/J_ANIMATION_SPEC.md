# J 입력 애니메이션 기준

## 고정 원칙

- J 상태도 `assets/room_background.bmp`와 `assets/sprite_sheet.bmp`의 같은 방·캐릭터를 사용한다.
- 방, 문, 책상, 침대, 플레이어를 J 프레임마다 다시 생성하지 않는다.
- `state-j-playing-canonical.png`은 승인된 구도 참고본이며, 실제 게임은 최종 매니페스트의 고정 레이어를 합성한다.
- AI로 다시 그린 `state-j-playing-frame-01.png`~`03.png`는 동작 참고용이며 게임 에셋으로 사용하지 않는다.
- HUD와 점수/시간 표시는 흔들리지 않는다.
- 흔들림 전의 방 배경을 720×720 정위치에 먼저 깔아 장면이 이동해도 좌우 가장자리에 검은 틈이 드러나지 않게 한다.

## 런타임 4프레임 루프

55ms마다 아래 순서로 반복한다. 좌표는 최종 720px 화면 기준이다.

| 프레임 | 장면 오프셋 | 키보드/마우스 표시 | 총구 화염 |
|---|---:|---|---|
| A | `(0, 0)` | 큰 입력 픽셀 1 | 큰 화염 기본 크기 |
| B | `(-6, 3)` | 큰 입력 픽셀 2 | 큰 화염 확대 |
| C | `(6, -3)` | 큰 입력 픽셀 1 | 큰 화염 기본 크기 |
| D | `(-4, 2)` | 큰 입력 픽셀 2 | 큰 화염 확대 |

## 별도 합성 요소

- 키보드와 마우스 입력 표시는 눈에 띄는 큰 주황·노랑 픽셀 도형으로 코드에서 그린다.
- 총구 화염은 모든 J 프레임에서 모니터 화면 내부에 큰 주황·노랑·밝은 코어로 합성하고, 교차 프레임마다 크기를 키워 맥동시킨다.
- 점수 상승 팝업은 모니터의 위·좌우·아래에서 매번 위치를 조금씩 바꾸며 동시에 쌓고, 서로 다른 위상으로 위로 이동시킨다. 값도 `+1/+2/+3/+5/+10`을 섞어 반복감을 줄인다.
- 점수 팝업은 내장 `PF스타더스트 Regular` 90자 비트맵 글리프를 큰 크기로 사용하고, 어두운 전용 뱅크로 외곽선을 합성한다. 여러 팝업이 동시에 보이도록 유지한다.
- 기본 화면에는 입력 픽셀, 총구 화염, 점수 팝업을 표시하지 않는다.
- 들킴 효과가 활성화되면 더 강한 흔들림, 붉은 테두리, `들켰다!` 연출을 우선 표시한다.

## 아빠 등장 예고

- 아빠 등장 직전에는 닫힌 나무문 상태를 유지하면서 `쿵.. 쿵..` 자막을 크고 굵게 표시한다.
- 예고 시간은 첫 등장 0.9초, 이후 0.7초, 마지막 20초 0.6초다.
- 예고가 끝나면 반쯤 열린 프레임 없이 바로 `열린 문 + 아빠 등장` 상태로 바꾸므로 문 비주얼은 두 종을 유지한다.
- `쿵.. 쿵..` 자막은 `PF스타더스트 Regular` 아틀라스의 `.`과 `쿵` 글리프를 사용하며 어두운 외곽선을 적용한다.
- 이 자막 외의 경고 흔들림, 반쯤 열린 문, `끼익`, 별도 발소리 애니메이션은 추가하지 않는다.

## 수면 조명과 FPS 화면

- 수면 상태에서는 방·가구·캐릭터를 함께 암전해 불이 꺼진 방으로 보이게 한다. HUD와 하단 조작 안내는 고정 UI이므로 암전하지 않는다.
- 자는 중 모니터가 꺼져 있으면 방 안에 모니터 광원을 표시하지 않는다.
- 자는 중 모니터가 켜져 있으면 주변 방은 어두운 상태를 유지하고, 밝게 보정한 도트 FPS 화면만 다시 합성한다. 별도 파란 광원 박스는 사용하지 않는다.
- 밝은 FPS 화면은 앉은 상태에서도 눈에 잘 띄어야 하며, J와 수면 연출은 같은 화면 스프라이트를 공유한다.
