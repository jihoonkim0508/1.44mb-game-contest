# Dad Game 최종 그래픽 매니페스트

## 고정 규칙

- 모든 게임 상태는 같은 무인 방 기준판과 고정 스프라이트를 합성한다.
- 문 상태는 `닫힌 나무문`과 `열린 문 + 이미 들어온 아빠` 두 개뿐이다.
- 아빠 등장 직전에는 닫힌 문 비주얼을 그대로 유지하고 `쿵.. 쿵..` 자막만 표시한다. 자막은 제3의 문 프레임으로 계산하지 않는다.
- 자막 반응 시간은 첫 예고 0.9초, 이후 0.7초, 마지막 20초 0.6초로 단계적으로 짧아진다.
- J 입력 중에만 큰 흔들림, 커진 입력 픽셀, 모니터 내부의 큰 총구 화염, 모니터 주변 여러 위치에 동시에 쌓이는 굵고 큰 점수 팝업을 표시한다.
- 들킨 순간에만 강한 흔들림, 붉은 충격 테두리, `들켰다!`를 표시한다.
- 수면 상태에서는 방 전체를 불을 끈 것처럼 암전한다. `수면·모니터 켜짐`은 어두운 방에서 밝게 보정한 FPS 화면만 남기며, 별도 파란 광원 박스는 표시하지 않는다.
- 허용하는 추가 연출은 J 입력, 실제 들킴, 수면 조명, 입장 직전 `쿵.. 쿵..` 자막뿐이다. 반쯤 열린 문, `끼익`, 별도 발소리 애니메이션·경고 흔들림, 기본 화면의 클릭·입력·점수 효과는 사용하지 않는다.
- 모든 런타임 문자는 `PF스타더스트 Regular` 90자(`.`·`쿵`·`몰` 포함)를 래스터화한 고정 아틀라스를 사용한다. 제목·경고·점수 팝업처럼 외곽선이 필요한 강조 문자는 어두운 전용 뱅크를 함께 사용한다. 시스템 폰트 대체가 없으므로 모든 PC에서 같은 모양이다.
- 폰트 원본은 재배포 제한 때문에 저장소에 포함하지 않는다. 아틀라스 재생성은 사용 권한이 있는 원본을 `tools/build_font_atlas.py --font ...`에 명시적으로 전달한다.

| 파일 | 규격 | 용도 |

## 스프라이트 좌표

| 이름 | 시트 좌표 `(x,y,w,h)` | 720 화면 좌표 `(x,y,w,h)` |
|---|---:|---:|
| 앉은 플레이어 | `(0,0,185,190)` | `(140,310,370,380)` |
| 자는 플레이어 | `(190,0,220,100)` | `(180,500,440,200)` |
| 열린 문·아빠 | `(190,105,116,164)` | `(520,18,196,328)` — 모니터 뒤의 왼쪽 18px은 가림 |
| 도트 FPS 화면 | `(310,105,164,95)` | `(168,154,328,190)` |
| PF Stardust 글리프 | `(0,272,512,240)` | 코드에서 문구별 중앙 정렬 |

글리프는 `16×20`, 32열이며 색상 뱅크는 크림·주황·초록·어두운 외곽선 순서로 각각 60px 높이를 사용한다. 원본은 Pinata의 PF Stardust Regular이며, 사용 범위는 [Noonnu 배포 페이지](https://noonnu.cc/font_page/393)를 따른다.

## 최종 상태 행렬

`앉음·모니터 켬`, `앉음·J`, `앉음·모니터 끔`, `수면·모니터 켬`, `수면·모니터 끔` 각각에 닫힌 문/아빠 등장 상태가 있어 총 10개다. 두 수면 상태는 암전을 공통으로 사용하되, 모니터가 켜진 상태에만 FPS 화면이 남는다. 아빠 등장 시 `수면·모니터 끔`만 안전하다. `쿵.. 쿵..` 예고는 닫힌 문 상태에 합성하는 런타임 UI이므로 상태 이미지 수를 늘리지 않는다. 정확한 파일 순서는 `STATE_INDEX.txt`에 기록한다.

- `assets/v2/door_half.png` 및 `assets/v2`의 이전 구도 스프라이트
